# 🔐 Random Password Generator (GUI Version)

A modern and secure **Password Generator Desktop Application** built using **Python** and **Tkinter**.  
This project allows users to generate strong random passwords with customizable options and a beautiful cybersecurity-inspired interface.

---

## 📌 Features

✅ Generate strong random passwords  
✅ Choose password length  
✅ Include:
- Letters
- Numbers
- Symbols

✅ Exclude similar characters (`0 O l 1 I`)  
✅ Password strength indicator  
✅ Copy password to clipboard  
✅ Modern dark-themed GUI  
✅ Input validation and error handling  

---

## 🖥️ GUI Preview

- Cybersecurity-inspired dark UI
- Interactive sliders and checkboxes
- Animated strength meter
- Clipboard integration

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Random Module
- String Module
- Pyperclip
